# Customer Churn Prediction Using Machine Learning and Deep Learning

## Practical No. 3

Comparative analysis of Machine Learning and Deep Learning models
for customer churn prediction.

## Aim

To build and compare Machine Learning and Deep Learning models
for predicting customer churn and analyze their performance using
standard evaluation metrics.

## Dataset

Telco Customer Churn Dataset

Source: IBM Sample Dataset / Kaggle

Problem Type: Binary Classification

Target Variable:
- Yes – Customer Left
- No – Customer Retained

## Models Used

### Machine Learning
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

### Deep Learning
- Deep Neural Network using TensorFlow

## Technologies Used

- Python

- TensorFlow

- Seaborn

## Preprocessing

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score
- Confusion Matrix
- Training Time
- Prediction Time
